# GTT — Canonical v3

**Status:** PLANNED  
**Canonical status:** NOT YET RELEASED  
**Generation:** GTT 3  
**Purpose:** Reserved canonical definition for the GTT 3 generation.

> This document describes the intended direction for GTT 3. It does not define capabilities as currently released GTT functionality.

---

## 1. GTT 3 Position

GTT 3 represents a major evolution of the GTT methodology beyond the GTT 2.x governance foundation.

The GTT 3 generation is expected to strengthen the relationship between governed context, architectural thinking, agents, and structured development workflows.

---

## 2. Planned Evolution

The GTT 3 definition is expected to address areas including:

- agent-assisted architectural thinking;
- structured THINK workflows;
- coordinated reasoning;
- stronger CLI support;
- richer governance automation;
- improved session continuity;
- expanded protection and proposal mechanisms;
- deeper integration with AI-assisted development environments.

These items remain planned until formally incorporated into a released GTT 3 specification.

---

## 3. GTT 3 Governance Principle

GTT 3 must preserve the fundamental GTT distinction:

> **Agent reasoning ≠ Change authorization.**

More capable agents must not remove the human decision boundary.

---

## 4. GTT 3 and Agents

GTT 3 may incorporate agents as participants in governed workflows.

GTT remains the governance layer.

The methodology must continue to avoid making its validity dependent on one particular agent, model, vendor, or ADE.

---

## 5. GTT 3 Status Rule

No GTT 3 capability should be represented as CURRENT merely because it appears in this planning document.

When GTT 3 is formally released, this document must be replaced or updated through the GTT version governance process and the released canonical definition must become authoritative.

---

## 6. Relationship with GTT 2.1

GTT 2.1 remains the released canonical generation until GTT 3 is formally released.

GTT 3 must preserve compatible foundational concepts unless an explicit governed change replaces them.

---

## 7. Planned Canonical Structure

The released GTT 3 canonical document should define at minimum:

- vision;
- purpose;
- principles;
- governance rules;
- terminology;
- capabilities/services;
- architecture;
- evidence model;
- agent model;
- human decision boundary;
- proposals;
- protection;
- session continuity;
- CLI;
- ADE independence;
- version-specific changes;
- conformance/alignment rules.

---

## 8. Release Boundary

**GTT 3 is not yet released.**

Until formal release, this document is planning context only.
